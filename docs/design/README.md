# TeamBeacon UI Mockups

This folder contains Oracle JET-oriented screen mockups for the desktop-first TeamBeacon experience.

## Files
- `teambeacon-ojet-mockups.html`: visual prototype for current TeamBeacon screens.

## Included Screens
1. Settings
2. Initiative Insights
3. Team Insights
4. Sprint Insights
5. Security / Incident Response / Releases
6. Team Dashboard

## How to View
Open the HTML file in any browser:

```bash
open docs/design/teambeacon-ojet-mockups.html
```

or

```bash
xdg-open docs/design/teambeacon-ojet-mockups.html
```

## Notes
- This is a mockup, not production components.
- Content and metrics are representative placeholders aligned to the product spec.
- Layout includes responsive behavior for narrower widths to support desktop and tablet previews.
