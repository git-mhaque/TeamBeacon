# TeamBeacon UI Mockups

This folder contains early screen mockups for the desktop-first TeamBeacon experience.

## Files
- `teambeacon-mockups.html`: visual prototype with six core screens.
- `teambeacon-ojet-mockups.html`: OJET-oriented mockup set for all TeamBeacon screens and migration target UX.

## Included Screens
1. Integrations & Field Mapping
2. Initiative Insights
3. Team Insights
4. Individual Insights
5. Current Sprint Work
6. Executive Report

## How to View
Open the HTML file in any browser:

```bash
open docs/design/teambeacon-mockups.html
```

```bash
open docs/design/teambeacon-ojet-mockups.html
```

or

```bash
xdg-open docs/design/teambeacon-mockups.html
```

```bash
xdg-open docs/design/teambeacon-ojet-mockups.html
```

## Notes
- These are mockups, not production components.
- Content and metrics are representative placeholders aligned to the product spec.
- Layout includes responsive behavior for narrower widths to support desktop and tablet previews.
